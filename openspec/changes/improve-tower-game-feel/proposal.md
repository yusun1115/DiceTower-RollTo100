# Proposal

## Why

현재 게임은 주사위 결과·층 이동·전투·보상을 대부분 즉시 바뀌는 숫자와 단순 도형으로 보여 주어, 탑을 오르는 기대감과 공격의 손맛이 약하다. 기존 규칙과 서버 판정을 유지하면서 중요한 행동에 짧고 명확한 시각·음향 반응을 붙여 CPU 대전과 온라인 대전 모두에서 플레이 흐름이 느껴지게 한다.

## What Changes

- 주사위를 누르면 즉시 굴림이 시작되고, 서버가 확정한 눈에 착지하며 빛·효과음·목적 층을 보여 준다. 응답 대기와 중복 클릭 방지를 명확하게 표시한다.
- 두 플레이어의 위치가 보이는 탑 진행 표시를 추가하고, 이동 시 층 숫자·플레이어 표식이 올라가는 연출과 도착 층 안내를 제공한다. 99층에서 6이 나오면 결과는 6, 목적지는 100층으로 구분한다.
- 일반층·상점·미니보스·최종보스 진입, 층 클리어, 턴 교대, 사망 하락, 승패에 서로 다른 짧은 연출을 제공한다. 이미 시작된 전투의 시야와 조작은 항상 유지한다.
- 공격 궤적, 투사체 잔상, 대시 잔상, 적 피격 반짝임·피해 숫자·처치 파편, 플레이어 하트 반응을 추가한다. 위험 장판과 유령은 장식보다 먼저 읽히게 한다.
- 상자 개봉·코인 획득·아이템 장착·구매·회복에 보상 피드백을 제공하고, 아이템 이름·희귀도·남은 사용 층·위험 효과를 이해하기 쉽게 보여 준다.
- 어두운 석조 탑, 금빛 주사위와 보상, 청록/주황 플레이어 표식으로 메뉴·HUD·던전의 테마를 통일한다. 저장소에 있는 미연결 이미지 중 적합한 것만 연결하고, 전투 공간을 우선하는 화면 계층을 구성한다.
- 연출을 화면 프레임 단위로 갱신하고 UI 버튼을 서버 갱신마다 제거하지 않도록 정리한다. 연출 사건은 서버에서 확정된 결과를 기준으로 한 번만 재생하며, 상대/CPU의 전투도 활성 플레이어 기준으로 관전한다.
- 효과음 음소거, 연출 줄이기, 브라우저 reduced-motion 설정, 이미지 로딩 실패·구버전 서버 응답에 대한 대체 표시를 제공한다.

## Capabilities

### New Capabilities

- `tower-journey-presentation`: 주사위 결과, 두 플레이어의 탑 진행, 층 진입, 턴 교대, 클리어·사망·승패를 설명하는 연출.
- `combat-feedback`: 활성 던전의 공격·이동·피격·처치·보상·위험 사건을 읽기 쉬운 시각·음향 피드백으로 전달하는 동작.
- `game-interface`: 탑 테마의 메뉴와 HUD, 안정적인 조작 요소, 아이템 표시, 연출/음향 환경설정과 접근성.

### Modified Capabilities

없음. 정식 `openspec/specs/` 목록은 현재 비어 있으며, 기존 `build-multiplayer-tower-game` 변경의 `match-session`, `tower-progression`, `dungeon-combat`, `item-economy` 규칙을 변경하지 않는 별도 표현 기능을 추가한다.

## Impact

- `apps/client/src/main.ts`, `styles.css`: 프레임 기반 렌더링, 안정적인 DOM, 주사위/탑 표시, 전투 효과, 음향·설정·테마를 담당하는 모듈로 정리한다.
- `apps/client/public/assets/`: 기존 주사위·캐릭터·배경·아이콘의 필요한 영역과 표시 크기를 정의하고, 사용할 리소스만 배포 가능한 형태로 연결한다. 원본 시트의 균일한 셀·투명 배경은 가정하지 않는다.
- `packages/shared/src/domain.ts`, `session.ts`, `apps/server/src/session-host.ts`: 현재 스냅샷만으로 놓치기 쉬운 최종 타격·사망·턴 종료를 위한 작은 선택적 표현 이벤트 계약을 추가한다. 주사위·피해·경제·타이머·승리 판정과 기존 행동 메시지는 유지한다.
- 검증: 이벤트 중복/누락 경계, 연출 중 입력, 100층 상한, CPU/온라인 관전, 위험 가독성, reduced-motion/음소거, 공개 배포 버전 호환성을 확인한다. Canvas 2D·TypeScript·Vite·WebSocket 스택을 유지한다.
- 범위 밖: 전투 수치 조정, 새 무기/버프/보스 패턴, 실제 넉백·무적 시간·서버 정지, 엔진 교체, 모바일 터치 조작, 계정/매칭, 새로운 대규모 아트 제작.
