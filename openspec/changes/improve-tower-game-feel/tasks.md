## 1. 안정적인 입력과 프레임 렌더링

- [x] 1.1 `main.ts`의 HUD/행동/상점 갱신을 안정적인 DOM으로 분리하고 동일 상태 갱신마다 버튼을 교체하지 않게 한다. 검증: 50ms 상태 갱신 사이에 준비·주사위·상점 버튼을 누르고 떼어도 합법 행동이 한 번 실행되고 키보드 포커스가 유지된다.
- [x] 1.2 하나의 프레임 루프에서 렌더링과 짧은 위치 보간을 처리하면서 기존 입력 전송 간격을 유지한다. 검증: 서버 메시지 사이에도 화면이 갱신되고 대시·층/턴 전환·사망에서 이전 위치를 끌고 오지 않는 경계 테스트와 플레이 확인을 통과한다.
- [x] 1.3 활성 플레이어의 전투를 렌더링하고 개인 자원과 관전 대상 정보를 구분한다. 검증: CPU 및 두 테스트 클라이언트 경기에서 상대 턴에 현재 상대 위치·적을 볼 수 있고 관전자의 입력은 전투를 변경하지 않는다.
- [x] 1.4 화면 변환/크기 변화에도 조준 좌표를 보존하고 설정 포커스·창 비활성화 시 눌린 키와 포인터를 정리한다. 검증: 크기 변경·포커스 이동 후 조준이 맞고 Space/클릭이 계속 눌린 상태로 남지 않는다. README에 입력/렌더/권위 상태의 경계를 기록한다.

- [x] 2.2 주사위 확정·층 클리어·사망 하락·턴 시작·승리 이벤트를 기존 전이의 정확한 지점에 기록한다. 검증: 99+6, 마지막 적 처치와 즉시 턴 교대, 하트 즉시 복구, 바닥 층 하락, 최종 승리 우선순위 테스트에서 사건의 이전/이후 층과 참가자가 정확하다.
- [x] 2.3 공격·대시 수락, 적/플레이어 피해·처치·회복, 유령 출현을 기록하고 런타임 삭제 전 좌표·원인을 캡처한다. 검증: 쿨다운 중 반복 입력은 성공 사건을 만들지 않고 최종 타격/즉사는 남으며, 연속 장판 피해의 표현 합산이 실제 피해를 바꾸지 않는다.
- [x] 2.4 상자 보상·아이템 획득·구매·무기 만료·재입고 사건을 기록하고 두 클라이언트에 같은 결과를 전달한다. 검증: 상점/코인/지속시간 기존 픽스처와 두 클라이언트 이벤트 일치 검증을 통과하고 거절된 구매에는 획득 사건이 없다.
- [x] 2.5 클라이언트 이벤트 소비기를 구현해 중복 제거, 첫 동기화 기준점, 장면 키, 숨김/복귀, 선택 필드 누락·알 수 없는 사건을 처리한다. 검증: 순수 소비기 테스트에서 반복 스냅샷이 효과를 재생하지 않고 과거 장면이 새 턴에 섞이지 않는다. 선택 필드와 호환성 규칙을 README 또는 `docs/game-feel.md`에 기록한다.

## 4. 주사위와 탑 이동 연출

- [x] 4.1 주사위 눌림·굴림·미해결 요청 잠금·2초 이후 대기·거절/연결 종료 복구를 구현한다. 검증: 느린 응답과 연타 픽스처에서 요청이 하나만 나가고 미확정 숫자를 결과로 처리하거나 자동 재전송하지 않는다.
- [x] 4.2 확정 눈 착지·짧은 금빛 강조·이전 층→도착 층·탑 표식 상승을 연결한다. 검증: 두 클라이언트에 같은 결과가 한 번 나타나고 99층에서 6은 눈 6/도착 100으로 표시되며 마지막 눈이 없는 구버전 응답을 추측하지 않는다.
- [x] 4.3 일반/상점/미니보스/최종보스 도착, 클리어, 턴 교대, 사망 하락, 승패의 비차단 배지를 구현한다. 검증: 보스층을 건너뛴 이동에는 보스 진입이 없고 마지막 처치→교대와 사망→교대가 구분되며 100층 도착만으로 승리하지 않는다.
- [x] 4.4 여정 상태기의 중복·빠른 CPU 턴·첫 동기화·복귀·승리 우선순위와 연출 중 입력을 확인한다. 검증: 관련 상태기 테스트를 통과하고 확정 후 주사위/도착 연출이 1초 이내 끝나면서 이동·조준·구매가 즉시 가능하다. 실제 사용한 시간값을 `docs/game-feel.md`에 기록한다.

- [x] 5.5 효과 TTL·입자/텍스트 상한과 선택적 미세 흔들림을 적용하고 지면 조준을 보존한다. 검증: 긴 보스전에서도 효과 수가 제한되고 실제 게임 객체가 사라지지 않으며 흔들림 중 조준이 유지된다. 상한 테스트와 프레임 측정값·조정 기준을 `docs/game-feel.md`에 기록한다.
