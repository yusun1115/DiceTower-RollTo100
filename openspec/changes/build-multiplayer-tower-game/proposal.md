# Proposal

## Why

이 프로젝트에 PC 브라우저에서 플레이할 수 있는 1대1 탑 등반 웹게임을 만든다. 주사위로 이동하는 경쟁 구조와 짧은 실시간 탑다운 던전 전투, 아이템 조합을 결합해 온라인 상대 또는 CPU와 반복해서 즐길 수 있는 게임 루프를 제공한다.

현재 프로젝트에는 구현 코드나 기존 사양이 없으므로, 이 변경은 게임의 핵심 플레이 규칙과 멀티플레이 계약을 처음 정의하는 기반이 된다.

## What Changes

- 1층부터 100층까지 주사위 결과에 따라 전진하는 1대1 탑 등반 게임 루프를 추가한다.
- PC 브라우저용 2D 탑다운 실시간 던전 전투를 추가한다.
- 일반층, 10층 단위 미니보스층, 100층 최종보스층, 랜덤 상점층을 추가한다.
- 플레이어 하트, 장애물·몬스터 피해, 사망 시 3층 하락, 제한 시간 후 등장하는 무적 유령 규칙을 추가한다.
- 몬스터·상자에서 얻는 코인, 공유 상점, 회복물약, 층수 기반 임시무기, 경기 동안 유지되는 패시브 버프를 추가한다.
- 무기와 버프를 조건·효과·위험요소로 조합할 수 있는 아이템 시너지 시스템을 추가한다.
- 같은 경기 시드로 던전 구성과 상자 보상 후보를 공유하되, 각 플레이어의 전투·체력·획득 상태는 독립적으로 처리한다.
- 상점 재고를 플레이어 간 공유하고, 구매 후 3번의 플레이어 턴이 지나면 재고를 전체 재생성한다. 한 번의 방문에서 여러 상품을 구매할 수 있게 한다.
- 방 코드 기반 온라인 1대1 모드와 동일 규칙을 사용하는 CPU 대전 모드를 추가한다.
- CPU 난이도 세 단계(쉬움, 보통, 어려움)를 지원하되, 보통 난이도를 기준으로 동작을 정의한다.

## Capabilities

### New Capabilities

- `match-session`: 방 코드 기반 온라인 대전, CPU 대전, 턴 순서, 공통 경기 시드, 플레이어별 독립 실행 상태를 관리한다.
- `tower-progression`: 주사위 이동, 100층 상한, 일반·보스·상점 층, 층 하락, 최종 승리 조건을 정의한다.
- `dungeon-combat`: 탑다운 실시간 이동·공격, 몬스터·장애물, 하트, 보스전, 제한 시간과 무적 유령을 정의한다.
- `item-economy`: 코인, 상자, 공유 상점, 회복물약, 임시무기, 지속 버프, 아이템 조합과 위험·보상 효과를 정의한다.

### Modified Capabilities

없음. 기존 사양이 없는 그린필드 프로젝트다.

## Impact

- 브라우저 클라이언트: 탑다운 렌더링, 입력, 전투, 던전 UI, 상점 UI, 하트·코인·아이템 표시가 필요하다.
- 게임 세션 서버: 턴 전환, 주사위 결과, 공통 시드, 공유 상점 재고, 승패와 전투 판정을 권위적으로 관리해야 한다.
- 콘텐츠 데이터: 층 템플릿, 몬스터, 보스, 장애물, 상자 보상, 상점 상품, 무기와 버프 효과를 데이터로 정의해야 한다.
- CPU 시스템: 동일한 게임 규칙을 사용하면서 이동·전투·상점 구매·아이템 조합을 수행하는 AI가 필요하다.
- 테스트: 결정적 시드 재현, 턴 전환, 상점 재고 경쟁, 아이템 지속시간, 사망·유령 판정, PvP와 CPU 모드의 규칙 일치를 검증해야 한다.
